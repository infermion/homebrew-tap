# Infermion Homebrew Tap

This is the official Homebrew tap for the Infermion CLI and TUI.

## Install

Stable channel:

```bash
brew install infermion/tap/infermion
```

Beta channel:

```bash
brew install infermion/tap/infermion-beta
```

Formulae are generated from validated Infermion native releases and updated by the protected
release workflow. The Infermion platform source repository is not published here.
